**SRAC (Student Result Analysis Core)** is Windows software for **VTU result analysis**. It helps faculty, HODs and exam cell staff of **Visvesvaraya Technological University (VTU)** affiliated engineering colleges in Karnataka turn semester results into ready-to-use PDF, Excel and Word reports in minutes instead of days.

*Formerly known as "Student Result Analysis Compiler".*

## What SRAC does

- **VTU semester result analysis** for a whole class or department, including **revaluation results**.
- **Reports in PDF, Excel and Word**, ready for college records.
- **You choose** which subjects go into each report.
- Handles **elective and special-mark subjects**.
- Runs on **Windows**.

## FAQ

**What is SRAC?**
VTU result analysis software for Windows that creates PDF, Excel and Word reports from semester results.

**Who is it for?**
Faculty, HODs and exam cell staff of VTU-affiliated engineering colleges.

**Is this repository the SRAC application?**
No. It is only the website code.

**Why was "Compiler" changed to "Core"?**
"Compile" was used in its everyday meaning, compiling many result files into one report. Because "compiler" has a specific meaning in computer science, the name was changed to "Core". The product and the short name SRAC are unchanged.
